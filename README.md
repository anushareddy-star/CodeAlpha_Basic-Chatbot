# 🤖 Basic Chatbot

## 📌 Project Description
This is a simple chatbot developed using Python as part of the CodeAlpha Python Programming Internship. The chatbot responds to predefined user inputs and exits when the user types "bye".

## ✨ Features
- Greets the user
- Responds to simple questions
- Accepts user input
- Exits when the user enters "bye"

## 🛠️ Technologies Used
- Python 3
- VS Code

## ▶️ How to Run
1. Download the project.
2. Open the terminal.
3. Run:
```bash
python basic_chatbot.py
```
